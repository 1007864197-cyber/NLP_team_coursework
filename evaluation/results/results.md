## Protocol and split

Classifier fitting/development use separate authored utterance groups in training/data/intents.json, with augmentation confined to training groups. Reference FAQ documents supply lexical retrieval knowledge. This fixed diagnostic query file is withheld from fitting, candidate selection and threshold selection; if reused for tuning, treat it as development data. Its author knew the supported category names, so it is not an independent benchmark.
Each single-turn query has fresh state. Each pipeline/mode pair has one excluded warm-up call. Latency covers a local reply or retrieve call, excluding application startup and HTTP/browser/network work; p95 uses linear interpolation of this sample.
Full-system accepted retrieval is a non-fallback answer with at least one returned reference source. Raw retrieval requires a non-fallback category and non-empty source_id. A correct accepted retrieval also matches the gold category. No confidence calibration, hallucination rate or answer-level factuality metric is claimed.
